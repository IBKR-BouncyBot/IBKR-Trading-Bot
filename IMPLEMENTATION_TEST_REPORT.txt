BouncyBot - IBKR Portable Trading Bot v3.2.2
Same-release BouncyBot branding, About information, and documentation maintenance
Date: 2026-07-26

IMPLEMENTED SCOPE
=================

1. BouncyBot application artwork
--------------------------------

The user-supplied BouncyBot artwork is stored as a real PNG at:

- Images/BouncyBot_logo.png

A square icon derived from the same artwork is stored at:

- Images/BouncyBot_app_icon.png
- Images/BouncyBot_app_icon.ico

The ICO contains 16, 24, 32, 48, 64, 128, and 256 pixel entries. The source
application, main window, and About dialog load the PNG icon through a resource
helper that works from both the repository and a PyInstaller one-directory
bundle.

The Windows build script now:

- supplies Images/BouncyBot_app_icon.ico to PyInstaller as the executable icon;
- bundles the runtime icon and full logo under Images/;
- validates that all required branding files exist before packaging; and
- copies the complete Images directory into the versioned release root so the
  packaged README keeps working.

2. About > Info screen
----------------------

A new top-level About menu contains an Info action. The dialog shows:

- the full BouncyBot logo;
- the product name and v3.2.2 version;
- a clickable project link to
  https://github.com/IBKR-BouncyBot/IBKR-Trading-Bot;
- the IBKR referral link from README.md;
- the Cardano/ADA, Midnight/NIGHT, Ethereum/ETH, and Solana/SOL support
  addresses from the README Thank me section; and
- a compact live-order/noncommercial-use notice.

The support addresses are read-only selectable fields so the operator can copy
without editing them. The external links use Qt's normal browser handling.

3. README and documentation maintenance
---------------------------------------

README.md now places the full logo immediately below its initial title. It also
documents the About > Info screen, updates the v3.2.2 release-history summary,
and keeps the Thank me links and support addresses consistent with the dialog.

The root docs directory now contains only the current v3.2.2 release-specific
note. Superseded v3.0.17, v3.0.18, and v3.0.19 notes are retained under
`docs/legacy/` and indexed by `docs/legacy/README.md`. Current documentation
links were updated to point to those archival paths.

4. Existing v3.2.2 GUI scope retained
-------------------------------------

The same-release source still includes the earlier v3.2.2 presentation changes:

- ticker and exact contract information above the current price;
- content-sized Cycle Audit Timeline columns;
- an asymmetric Timeline allocation that gives the stage-transition table the
  remaining width and limits the guard/risk table to its required width; and
- top-aligned Orders, Executions, and Decision events tables.

5. Safety and compatibility
---------------------------

No strategy, order-construction, price-selection, risk, RTH/session, recovery,
fill, commission, P/L, reconnect, or persistence decision changed.

No SQLite table, column, index, or migration was added. Existing v3.2.1 and
v3.2.2 portable databases, active cycles, orders, executions, settings, audit
events, and market-capture files remain compatible.
