ELEVEN REQUESTED CORRECTIONS
1. All ten status boxes use equal stretch, a zero explicit minimum width and
   horizontal Ignored size policy so content hints cannot widen just Trading
   or Position. Status/detail text wraps; price/trigger and remaining invested
   cost remain right-aligned. The lock retains its fixed 48-pixel width.
2. Total BUY cost is renamed Total buy cost, including the metric update key.
   Actual-fill/fee calculation and history Invested are unchanged.
3. OrderRef retains read-only wrap-anywhere plain text, exact selection/copy and
   bounded internal scrolling. A targeted QTextEdit#MetricValue rule overrides
   the generic black/monospace log style: matching card background/foreground,
   proportional Segoe UI/sans-serif font, no inner border and no extra padding.
   The existing light/dark conversion applies to that targeted rule too.
4. Raw API table: five content-sized Field columns alternate with five Value
   columns that share spare horizontal width. Stretch modes are reapplied after
   autosizing on refresh/show; narrow-window scrolling remains available.
5. Strategy input map: minimum height reduced from 560 to 420 (25 percent),
   block height 90 to 72, row spacing 116 to 82. All sixteen blocks, lane labels,
   calculations, font sizes and footer remain. Text rectangles fit each block.
6. A single stage ribbon is created in the fixed shell above status and tabs,
   not inside the Live Strategy scroll area. It updates on every snapshot even
   while another tab is selected; its existing unchanged-stage cache remains.
7. Average net P/L follows Best net P/L and Worst net P/L in reading order.
   Twelve summary cards remain in three columns and four rows; formulas and
   summary/filter scope are unchanged.
8. All linked-hover code is removed. The four graph _draw_hover_overlay methods
   and CycleTimelineWidget.paintEvent are AST-identical to the corrected v4.0.0
   source. This includes removing unintended undefined linked-state references
   in three other graph overlays. Crosshairs draw only in the hovered plot.
   Existing shared time axis, zoom/pan and aligned Timeline tables are retained.
9. Audit Orders retains a top-aligned bounded table; OrderRef stretches across
   unused horizontal width. Editing remains disabled and scrolling remains.
10. Audit Executions uses the same full-width final-OrderRef policy.
11. Market capture has zero extra container margins, a top-aligned summary,
    stretching summary Value and preview Capture ZIP columns, and a trailing
    spacer when no preview rows exist. It no longer vertically centers a lone
    summary. A populated preview can consume the remaining height. Tables and
    the source-file list scroll independently, without a page-level scroll area.

VALIDATION LIMITS / REQUIRED WINDOWS GATE
Ruff and Pyright are not installed in this host and installation attempts did
not obtain them. The required quality command returned exit code 1 for missing
tools; neither check is claimed as passing. Python grammar checks and pytest
are not substitutes for those tools. The configured Pyright application files
are byte-identical to the baseline.

PySide6 could not be installed here. GUI tests use observable Qt doubles and
recorded painter coordinates, not actual Qt/Windows rendering. They verify the
requested layout/style policies and behavior, not native font metrics or screen
pixels. There was no Windows/PyInstaller build or paper/live IB Gateway test,
and no real broker order was submitted during validation. No native EXE is
included. On Windows run run_all_tests.bat, then build_windows.bat. Complete the
100/150/200-percent scaling, theme-switch, fixed-ribbon, long-OrderRef, table
resize/scroll and independent-crosshair checks in docs/TEST_PLAN.md before
unattended deployment. Do not disable trading safeguards to test the layout.
