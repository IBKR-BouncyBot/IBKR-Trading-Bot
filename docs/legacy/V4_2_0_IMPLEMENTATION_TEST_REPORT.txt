IMPLEMENTED CHANGES
1. Trading and Position detail labels moved into the upper title row, aligned
   top/right, with the exact same font styling as their upper-left titles.
   Main status and position quantity remain below, using the full box width.
2. Removed only the Cycle Timeline linked-hover overlay and its calls. Each
   graph retains its local cursor, price/readout, data and existing time mapping.
3. Reconciliation now fits all eight wrapped comparison rows without internal
   table scrollbars. Columns stretch with the viewport, and row fitting responds
   to width, content, font and style changes. A page scroll area keeps controls
   reachable when the window is too short. Guided actions use two columns;
   advanced actions no longer have a fixed height cap.
4. The audit Summary details table refits on the same changes; content beyond
   its existing height cap remains reachable with vertical scrolling. Shared
   table sizing includes style-derived horizontal scrollbar height, and capped
   all-row tables no longer hide overflow.
5. Deferred fitting uses a single-shot timer owned by its table, coalesces
   updates, suppresses recursive section signals, and cancels pending work on
   direct fitting. Ownership also ties the timer lifetime to the widget.
6. Application/package/build metadata, current documentation and affected
   regression expectations updated to 4.2.0. Prior note/report retained intact.
